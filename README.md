# vibe-kanban-hang-out

vibe-kanbanを使い倒して遊ぶためのプロジェクトです。

## プロジェクト概要

このリポジトリは、vibe-kanbanのタスク管理機能とAIエージェントを活用した実験・学習プロジェクトです。
様々なアプリケーションを作成し、AIエージェントによる自動開発の可能性を探ります。

## プロジェクト構造

```
vibe-kanban-hang-out/
├── README.md              # このファイル
├── .claude/               # Claude Code設定
│   ├── commands/         # カスタムスラッシュコマンド
│   └── hooks/            # フック設定
├── app1/                  # アプリケーション1
│   ├── Dockerfile        # Docker環境（必要に応じて）
│   └── ...
├── app2/                  # アプリケーション2
│   └── ...
└── ...
```

### ディレクトリ構成の原則

- **root**: 基本的な設定ファイル（`.claude/`, `README.md`など）を配置
- **各アプリフォルダ**: rootに対して簡単な名前のフォルダを作成
- **環境設定**: 必要に応じて各アプリごとにDockerなどの環境を構築

## 使用するエージェント

- **CLAUDE_CODE**: メインのAIエージェント（原則として使用）
- **CODEX**: 補助的に使用

## 開発の流れ

1. vibe-kanbanでタスクを作成
2. タスクをCLAUDE_CODEまたはCODEXに割り当て
3. エージェントが自動的にコードを生成・実装
4. レビュー・調整
5. 完了

## vibe-kanbanの活用

このプロジェクトでは、vibe-kanbanのMCPサーバー機能を使用してタスク管理を行います。

主な機能:
- `list_projects`: プロジェクト一覧
- `list_tasks`: タスク一覧
- `create_task`: タスク作成
- `start_task_attempt`: タスク実行開始
- `update_task`: タスク更新
- `delete_task`: タスク削除

## 始め方

1. タスクを作成:
   ```
   vibe-kanbanのツールを使用してタスクを作成
   ```

2. タスクを開始:
   ```
   CLAUDE_CODEまたはCODEXでタスクを開始
   ```

3. 実装を確認・調整:
   ```
   生成されたコードをレビューし、必要に応じて調整
   ```

## 注意事項

- このプロジェクトは実験・学習目的です
- 本番環境での使用を想定していません
- AIエージェントの出力は必ずレビューしてください

## ライセンス

このプロジェクトは個人的な実験用途のため、特定のライセンスは設定していません。
