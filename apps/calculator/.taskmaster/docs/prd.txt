# 電卓アプリケーション PRD (Product Requirements Document)

## プロジェクト概要

### 目的
シンプルで使いやすく、かつ高機能な電卓Webアプリケーションを開発する。基本的な四則演算から科学計算、履歴機能まで、日常業務から学習まで幅広く対応できる電卓を提供する。

### 目標
- 直感的で美しいUIを持つ電卓の実装
- レスポンシブデザインでデスクトップ・モバイル両対応
- 計算履歴の保存・管理機能
- キーボード操作対応
- エラーハンドリングの実装
- テストカバレッジ80%以上
- アクセシビリティ対応(WCAG 2.1 AA準拠)

## コア機能

### 1. 基本電卓機能
- 四則演算(+, -, ×, ÷)
- クリア機能(AC: All Clear, C: Clear)
- バックスペース機能(DEL)
- 小数点計算
- パーセント計算
- 符号反転(+/-)
- 連続計算機能

### 2. 科学電卓機能(拡張モード)
- 三角関数(sin, cos, tan)
- 逆三角関数(asin, acos, atan)
- 対数関数(log, ln)
- 指数・累乗(x², x³, xʸ)
- 平方根・n乗根(√, ³√)
- 円周率(π)、自然対数の底(e)
- 階乗(n!)
- 括弧演算

### 3. 計算履歴機能
- 計算履歴の表示(最新20件)
- 履歴からの再計算
- 履歴のクリア
- 履歴のローカルストレージ保存
- 履歴のエクスポート(JSON/CSV)

### 4. UI/UX機能
- レスポンシブデザイン
  - デスクトップ: 横幅400px-600px
  - モバイル: 画面幅に応じて最適化
- ダークモード/ライトモード切替
- キーボードショートカット対応
  - 数字キー: 0-9
  - 演算子キー: +, -, *, /
  - Enter: 計算実行
  - Escape: クリア
  - Backspace: 削除
- ボタンクリック時のフィードバック(アニメーション)
- 長い数値の自動フォーマット(桁区切り表示)

### 5. エラーハンドリング
- ゼロ除算エラー
- 無効な演算エラー
- オーバーフロー/アンダーフローエラー
- エラーメッセージの表示
- エラー状態からの回復

## 技術要件

### フロントエンド
- React 18+ (関数コンポーネント + Hooks)
- TypeScript
- CSS Modules または Tailwind CSS
- Zustand または Context API (状態管理)
- Vitest + React Testing Library (テスト)
- ESLint + Prettier (コード品質)

### ユーティリティ
- mathjs または decimal.js (高精度計算)
- clsx (クラス名管理)
- date-fns (日時フォーマット - 履歴用)

### 開発環境
- Vite (ビルドツール)
- Node.js 18+
- npm または pnpm

## データ構造

### 計算履歴
```typescript
interface CalculationHistory {
  id: string;
  expression: string;
  result: number | string;
  timestamp: number;
}
```

### 電卓状態
```typescript
interface CalculatorState {
  display: string;
  previousValue: number | null;
  currentOperator: Operator | null;
  shouldResetDisplay: boolean;
  memory: number;
  history: CalculationHistory[];
  mode: 'basic' | 'scientific';
  theme: 'light' | 'dark';
}
```

## UI設計

### レイアウト
1. ヘッダー
   - タイトル
   - モード切替ボタン(基本/科学)
   - テーマ切替ボタン

2. ディスプレイエリア
   - 計算式表示(小さめフォント)
   - 結果表示(大きめフォント)
   - エラーメッセージ表示エリア

3. ボタングリッド
   - 基本モード: 4列×5行
   - 科学モード: 5列×7行

4. 履歴パネル(トグル表示)
   - 履歴リスト
   - クリアボタン
   - エクスポートボタン

### カラースキーム
- ライトモード
  - 背景: #FFFFFF
  - ディスプレイ: #F5F5F5
  - 数字ボタン: #E0E0E0
  - 演算子ボタン: #FF9500
  - イコールボタン: #34C759

- ダークモード
  - 背景: #1C1C1E
  - ディスプレイ: #2C2C2E
  - 数字ボタン: #505053
  - 演算子ボタン: #FF9F0A
  - イコールボタン: #30D158

## パフォーマンス要件
- 初回ロード時間: 2秒以内
- ボタンクリック反応時間: 100ms以内
- 計算処理時間: 50ms以内
- Lighthouse スコア: 90点以上(全カテゴリ)

## アクセシビリティ要件
- すべてのボタンに適切なaria-label
- キーボードナビゲーション対応
- スクリーンリーダー対応
- 十分なコントラスト比(WCAG AA準拠)
- フォーカスインジケーター

## セキュリティ要件
- XSS対策(ユーザー入力のサニタイズ)
- eval()関数の使用禁止
- ローカルストレージのデータ検証

## テスト要件
- ユニットテスト
  - 計算ロジック
  - 状態管理
  - ユーティリティ関数
- インテグレーションテスト
  - ボタンクリック動作
  - キーボード入力
  - 履歴機能
- E2Eテスト(オプション)
  - 主要ユーザーフロー

## デプロイ要件
- Vercel または Netlify でホスティング
- 自動ビルド・デプロイ(CI/CD)
- 環境変数管理
- エラーログ記録(オプション)

## 将来的な拡張機能(Phase 2以降)
- 単位換算機能
- 通貨換算機能(API連携)
- グラフ描画機能
- 方程式ソルバー
- マルチテーマ対応
- PWA対応(オフライン利用)
- 計算履歴の同期(クラウド保存)

## 成功指標
- ユーザビリティテストでの満足度: 4.5/5.0以上
- モバイル・デスクトップでの動作確認: 100%
- バグ報告数: 重大バグ0件
- テストカバレッジ: 80%以上
- アクセシビリティスコア: WCAG AA準拠
